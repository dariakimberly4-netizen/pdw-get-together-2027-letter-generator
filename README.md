# PDW Get-Together 2027 Letter Generator

A browser-based sponsorship letter generator for Parkinson's Disease Warriors Philippines.

## What it does

- Tracks Control No., Date, Recipient Name, Gender, Company/Address, C/O PD Warrior, and Status.
- Keeps **Gender** and **C/O PD Warrior** internal only; they are not printed on the letter.
- Generates a one-page PDF sponsorship letter.
- Includes the approved Get-Together 2027 event details and solicitation wording.
- Saves the tracker locally in the browser using localStorage.
- Can generate all pending letters and export the tracker as CSV.

## Publish with GitHub Pages

1. Open this repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select **main** and **/(root)**, then click **Save**.
5. After GitHub finishes publishing, open:
   `https://dariakimberly4-netizen.github.io/pdw-get-together-2027-letter-generator/`

## Privacy note

This version stores recipient data only in the browser where it is entered. It does not send the tracker to a server.
